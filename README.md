# ComfyUI·Info — ComfyUI 图片信息查看器

一个纯前端的本地工具：把 AI 生图（单张、多张或整个文件夹）拖进来，自动扫描其中的 ComfyUI 原图和 A1111/WebUI 格式图片，直接读取内置元数据——提示词、模型、CFG、步数、种子、采样器、LoRA 等信息一目了然；工作流 JSON / A1111 参数文本文件拖进来也能直接解析，无需配图。

**所有解析都在浏览器本地完成，图片不会上传到任何服务器。**

## 功能

- **四种添加方式**：单张 / 多张（文件选择器）、整个文件夹（递归扫描）、直接拖拽文件或文件夹到窗口、Ctrl / ⌘+V 直接粘贴文件；目录内文件的相对路径会被保留，用于去重、展示与导出溯源（不同子目录下的同名文件不会被误去重）；无扩展名 / 生僻扩展名的图片按文件头魔数自动识别；Chromium 系浏览器的目录选择走 File System Access API，会记住目录供一键重扫
- **一键重扫**：记住上次扫描的目录后，顶栏「重扫」按钮增量更新——只添加新文件，已有图片按指纹回挂去重，不会重复解析；支持记住多个目录并在「目录」菜单中随时切换重扫目标；权限需重新授权时自动弹窗。支持多目录时在「目录」菜单一键**全部重扫**（无权限目录单独计数）；还可打开「自动重扫」开关，按可调间隔（5 / 10 / 30 / 60 秒，偏好记忆）自动增量扫描记住的目录，边出图边看（权限未授予时静默重试，手动授权后自动恢复）
- **拖入参数文件直接解析**：`.json` / `.txt` 参数文件（ComfyUI API / UI 格式工作流 JSON、A1111 parameters 文本）拖进来即按元数据处理，无需配图——UI 格式工作流有兜底的参数提取；JSON 须含工作流节点结构、文本须有参数行特征才判为对应来源，普通文本不会被冒充成参数；参数文件以无预览的「纯参数」卡片显示，参数照常查看 / 搜索 / 导出
- **自动识别来源**：自动区分 ComfyUI 原图、A1111/WebUI 图片和无元数据的普通图片，默认只显示 ComfyUI 原图，可一键切换
- **A1111 兼容格式支持**：ComfyUI 生态的 Civitai 兼容保存节点（Image Saver 等）和在线平台导出的图，参数以 A1111 文本格式存储——同样完整解析，含 `<lora:…>` 标签、Lora hashes、Model hash（识别同名模型的版本）与高清修复两阶段；若参数文本尾部内嵌了 workflow JSON，会自动升级按 ComfyUI 工作流解析
- **完整参数解析**：
  - 正向 / 负向提示词（ComfyUI 沿工作流连线自动回溯，兼容常见组合节点；SDXL 的 `text_g` / `text_l` 与 Flux 的 `t5xxl` / `clip_l` 双编码槽同样识别）
  - 模型（checkpoint / unet）、LoRA 及强度
  - VAE、Clip Skip、放大模型（Upscale Model，含 A1111 的 `Hires upscaler`；`Latent` / `None` 不作为模型）、ControlNet 模型名
  - 采样器、调度器、步数、CFG、种子（64 位大数不丢精度）、重绘幅度；兼容 KSampler 与 SamplerCustom / SamplerCustomAdvanced 分离式拓扑（参数沿 noise / guider / sigmas 连线回溯）
  - 出图尺寸与批量张数；识别到高清修复配置时自动推算放大后的最终输出尺寸
  - 多阶段采样（如高清修复两阶段）按节点顺序全部列出
- **工作流提取**：查看 / 复制 / 下载 Prompt JSON 和 UI 工作流 JSON，一键复制 A1111 风格参数摘要（正向 + 负向 + Steps / Sampler / Seed / Size 等键值，LoRA 转回 `<lora:…>` 标签，多阶段附单行摘要，可直接贴回 WebUI 复现），复制或下载的 workflow.json 可直接粘贴（Ctrl/⌘+V）或拖回 ComfyUI 画布恢复工作流
- **详情页图片操作**：详情大图右上角一键复制图片到剪贴板（JPEG / WebP 自动经画布转 PNG，可直接贴进聊天 / 文档工具）或下载原图；点击进入全屏放大后可**滚轮缩放（以光标为锚，最高 12×）、拖拽平移、双击复位**，适配视图下点击关闭；大图左下角显示实际分辨率，与参数出图尺寸不一致时标注放大 / 缩小倍数（高清修复 / 后处理一眼可辨，非等比例差异提示「与参数尺寸不一致」）；参数区块（模型 / VAE / Clip Skip / 尺寸 / 采样器 / 种子 / LoRA 等）行尾可**一键套用对应筛选**并回到画廊（筛选变化自动回到列表顶部），从任意出图快速跳到同参图集；文件行可一键**与上一张 / 下一张对比**（沿当前筛选顺序，双方已解析才可点）
- **筛选与搜索**：按模型筛选、按来源筛选、按提示词 / 文件名与路径 / 模型 / LoRA（含哈希）/ 采样参数搜索，支持结构化语法——字段限定 `model:xxx`、`lora:xxx`、`seed:123`、`path:目录`，提示词定向 `pos:xxx` / `neg:xxx`（仅匹配正向 / 负向提示词，裸关键词搜全域）；采样与资产定向 `sampler:xxx` / `scheduler:xxx` / `vae:xxx` / `upscale:xxx` / `controlnet:xxx`；存在性条件 `has:lora|vae|hires|upscale|controlnet|tag`（只看带某要素的图，可配 `-` 排除）；种子范围 `seed:>100`（支持 > / >= / < / <=，64 位大种子按数值比较不丢精度）；日期范围 `date:>2026-01-01`（支持 > / >= / < / <=，年 / 月前缀自动展开为区间端点）；数值字段范围 `steps:>30` / `cfg:<8` / `w:>=1024` / `h:<768` / `batch:2` / `clip:>1`（无操作符为精确相等）；带引号的字段值可含空格 `"model:a b"` 或 `model:"a b"`（两种引号位置均可，可与 `-` 连用，如 `-"model:a b"`）；`-` 前缀排除条件 `-关键词` / `-model:xxx`（任一命中即整条排除）。正向条件按 AND 组合，大小写不敏感，搜索框悬停或点按输入框旁的问号按钮均有语法速查（触屏 / 键盘可达）；写了永远不会命中的条件（非法 `date:` 值、残缺 `seed:` / 数值条件、未知 `has:` 要素等）会在搜索框旁给出**语法警告**并说明原因，不再默默清空结果，未闭合引号按「匹配到结尾」的短语处理；最近用过的搜索词记入**历史**一键重用（去重置前，最多 10 条，跨会话记忆），筛选与搜索状态跨会话记忆；常用筛选组合可存为命名**预设**一键切换（搜索 / 模型 / 来源一并还原，同名覆盖，跨会话记忆）；有筛选且确实隐藏了图片时，状态行显示筛选命中数；**激活筛选以 chips 展示**（F5），每个条件（含搜索串里的单个 token）可单独移除，支持一键清除全部；可切换按文件时间新→旧 / 旧→新（扫描输出目录时即生成顺序，失败项始终靠后）、按文件名 A→Z / Z→A（跨来源全局排序）、按工作流聚类排序（同一工作流的出图聚成组，组按最新出图时间排列，卡片显示组内序号「第 x/y 张」），偏好自动记忆；存在同工作流同种子的同源出图时（卡片标「同源 x/y」），可一键「只看重复」定位重复出图，再点「每组保留最新」整批清掉各组旧张（重跑同参图太多时一键瘦身）；筛选结果为空时提示被隐藏的数量并支持一键查看全部
- **随机抽一张**：顶栏骰子按钮从当前筛选结果等概率抽选并打开详情，适合「随便看看找灵感」或从大量出图里随机抽查；
- **模型库**：顶栏按钮打开按主模型聚合的抽屉——每个模型列出出图张数、最近出图日期与 A1111 Model hash（同名模型区分具体版本），点击行即只看该模型的全部出图（F4）
- **生成统计**：对已解析出参数的图片聚合模型 / LoRA / 采样器使用频次，附按天出图趋势、按目录聚合、分辨率分布与提示词高频词 Top-N，条形排行展示，点击条目直接应用对应筛选（目录走 `path:"…"`，含空格的目录名也可用），可一键导出统计 CSV，快速回答「最常用的模型出过多少张图」「最近哪几天出图最多」「哪个子目录出图最多」
- **参数对比**：多选两张已解析图片即可并排对比模型 / 采样参数（多阶段逐项对齐）/ LoRA / 提示词，差异项高亮，便于定位两次出图之间的参数变化；对比抽屉可一键交换 A / B
- **收藏星标**：卡片悬停星标按钮（已收藏时常显）或详情页一键收藏，批量操作条可批量收藏 / 取消收藏选中（选中已全部收藏时自动切换为取消），收藏按文件指纹跨会话记忆——清空列表 / 移除条目不影响收藏记录，重新拖入同指纹文件或存档恢复后标记自动生效；有收藏时顶栏出现「只看收藏」开关一键筛选
- **自定义标签**：详情页为任意图片（含存档项、无元数据图）添加 / 移除标签（按文件指纹跨会话记忆，与收藏同一套语义——清空列表 / 移除条目不动账，重新拖入同指纹文件自动生效），输入框带全库标签频次建议；批量操作条可**批量打标 / 批量移除标签**（带频次建议）；统计抽屉新增「自定义标签」面板：按打标张数排序，点击即 `tag:"…"` 定向筛选，支持行内重命名（全库同步替换）与全库删除；标签点击即 `tag:"…"` 定向筛选，搜索语法支持 `tag:xxx` 与 `has:tag`（可配 `-` 排除），随存档备份迁移；
- **移除与导出**：卡片悬停可单张移除（同步回收预览内存）；支持 Ctrl / ⌘+点击多选、Shift+点击区间选择（或 Ctrl+空格切换选中），浮动操作条提供全选筛选结果、批量移除、批量复制正向提示词、批量复制 A1111 风格参数摘要（每张图一个块并附文件名）与导出选中；当前筛选结果一键导出 JSON / CSV（含相对路径列，CSV 带 BOM 可直接用 Excel 打开，文本单元格做公式注入防护，`= + - @` 开头的内容不会被 Excel 当公式执行）、把全部工作流打包为 ZIP（按相对路径存放 prompt / workflow / 参数文本 + manifest），或把选中 / 筛选的**原图打包为 ZIP**（按相对路径存放原文件本体，条目路径逐段消毒——消解 `..` / 盘符 / 非法字符，杜绝 zip-slip，流式计算校验不整载内存；无 ZIP64，条目超 65535 或总量超 4GB 时导出前置拒绝并明确提示，绝不静默产出损坏文件）、**训练集打包 ZIP**（每张图附带同名 .txt 标注文件，内容为正向提示词，可直接投喂 kohya 等训练管线，无参数图片给空标注占位便于人工补写），便于数据集整理与批量分析
- **无元数据诊断**：识别不出参数时，详情页显示检测线索（如「包含 Adobe XMP 编辑信息，生成参数已被 Photoshop 处理清除」），一眼看出原因；元数据存在但解析失败（如内嵌工作流 JSON 被截断损坏）时会单独提示，原始 JSON 仍可查看 / 复制用于排查
- **解析失败可见**：损坏或读取失败的文件不会被静默忽略——统计区显示失败数量（点击直达），来源筛选可切换到「解析失败」，详情页展示错误原因并支持一键重试，工具栏还能批量重试全部失败项（存档失败项需重新拖入原文件）
- **大列表依然流畅**：状态行实时显示已加载数量与文件总大小；画廊虚拟滚动、只渲染视口内卡片，预览 URL 惰性创建；解析结果节拍式批量应用，批量扫描大目录时界面不卡顿；滚深后右下角「回到顶部」一键返回；浏览器标签页标题同步显示已加载数量（有筛选时显示「命中/总数」），多开页签对照时一眼可辨
- **缩略图大小调节**：顶栏滑杆实时调整画廊卡片尺寸（150–420px，虚拟滚动列数随之重算），偏好记忆；**安全模式**一键模糊全部缩略图（悬停卡片临时揭示），公共场合 / 屏幕分享防走光，偏好记忆；详情 / 对比 / 统计三个抽屉左缘可**拖拽调宽**（420px 至近全屏），各抽屉独立记忆
- **悬停快速预览**：画廊卡片上悬停片刻即浮出未裁切的原比例大图，看构图不必逐张开详情；任何滚动即收起，安全模式下不弹（防走光优先）
- **会话持久化**：解析结果（来源、参数、诊断信息、失败原因）自动存入浏览器 IndexedDB，仅存本机、不含图片本体；启动时自动申请浏览器**持久存储**（授予后存档不会被浏览器在磁盘紧张时自动清理），顶栏持久化状态徽章的悬停提示可见**存档占用 / 配额与授予状态**，配额写满等失败给出可行动提示（先导出备份再清理）；刷新或关闭后重新打开，历史记录仍在并标记「已存档」，把原文件重新拖入即按指纹自动回挂预览，无需重新扫描；JPEG / WebP / PNG eXIf 里内嵌缩略图的存档项**直接显示缩略图预览**（F2，惰性物化不占启动内存）；清空列表会连历史记录一起清除。存档大文本（工作流 / 参数 JSON）按内容寻址去重存储，同工作流批量出图的存档体积降一个量级；顶栏「存档」菜单可一键导出 / 导入备份（含参数、诊断信息、收藏标记与自定义标签，防清库、可跨设备迁移——收藏 / 标签按指纹随备份走，导入后恢复的记录自动带星标与标签）
- **深色 / 浅色主题**，未设置过时跟随系统偏好并实时跟随切换（手动切换后写入显式偏好）；**中英双语界面**，默认跟随浏览器语言，偏好记忆
- **PWA 离线可用**：在线版注册 Service Worker（仅 https / localhost 环境生效），可从浏览器安装到桌面独立窗口、断网后仍能打开使用；`file://` 单文件版不受影响
- **键盘可操作**：Tab 聚焦卡片，Enter / 空格打开详情；抽屉内 ← / → 按当前筛选顺序浏览（大图两侧也有上一张 / 下一张按钮），可开启自动播放逐张浏览（每 4 秒切换，末张 / 关抽屉自动停止）、Esc 关闭，关闭后焦点返还来源卡片；**F 收藏 / Delete 删除当前图**（删除后按筛选顺序同位置补位前进，浏览连续不打断）；画廊内 Ctrl / ⌘+A 全选当前筛选结果、Esc 清空选择（输入框内保留原生行为）
- 支持格式：PNG（tEXt / zTXt / iTXt / eXIf 块）、JPEG、WebP（EXIF UserComment），以及工作流 JSON / A1111 参数文本（.json / .txt）

GitHub Pages 在线版（与本地单文件版功能一致，数据同样只存浏览器本地）：

**https://xjasonshane.github.io/ComfyUI-Info/**

在线版是 PWA：可通过浏览器「安装应用」添加到桌面，以独立窗口使用；Service Worker 做离线缓存，断网后依然能打开（解析数据照常只存浏览器本地）。

推送 main 后自动部署：CI（lint + 格式检查 + 类型检查 + 单测与覆盖率门禁 + 体积预算 + e2e）全部通过后，`.github/workflows/pages.yml` 复用其构建产物发布；也可在仓库 Actions 页手动触发 Deploy 工作流（完整门禁后自行构建）。打 `v*` tag 会触发 **Release** 工作流：门禁通过后自动创建 GitHub Release 并附上单文件产物（`comfyui-info-<tag>.html`），离线分发从这里取。首次启用需在仓库 **Settings → Pages → Build and deployment** 把 Source 设为 **GitHub Actions**。

## 使用

```bash
npm install
npm run dev       # 开发（默认 http://localhost:5173）
npm run build     # 构建产物为单个 dist/index.html（含 vue-tsc 类型检查）
npm run preview   # 预览构建产物
npm run test      # 单元测试（解析器 / store / 导出 / 工具）
npm run test:coverage # 单测 + 覆盖率报告（src/lib 设门禁阈值）
npm run typecheck # 类型检查（src / tests / e2e 全量；build 内含 src 部分）
npm run test:e2e  # Playwright e2e 冒烟测试（自动重新构建并用 vite preview 提供服务，首次需 npx playwright install chromium）
npm run lint      # ESLint 检查
npm run format    # Prettier 格式化（format:check 只校验不写入）
```

GitHub Actions 在 push / PR 时自动执行 lint + 格式检查 + 类型检查（覆盖 src / tests / e2e）+ 单测（含 src/lib 覆盖率门禁）+ 构建 + **单文件体积预算**（gzip 超 260KB 即红）+ e2e（失败自动上传 trace 便于排查；同分支连续推送自动取消在途流水线）。

`npm run build` 产出的是**单文件** `dist/index.html`（约 840 KB，gzip 后约 250 KB），直接双击即可在浏览器中离线使用，无需任何服务器。

解析结果会自动持久化到浏览器的 IndexedDB（图片本体不入库，数据不出本机）：刷新或关闭后重新打开，历史记录以「已存档」卡片显示，参数照常查看、搜索与导出；把原文件重新拖入即按指纹自动回挂预览。启动时会申请浏览器持久存储并在顶栏徽章展示占用 / 配额，配额写满等失败会提示先导出备份再清理；IndexedDB 不可用的环境（部分 file:// 场景、隐私模式等）会在启动时探测并自动降级为纯内存模式，行为与旧版一致。清空列表会连历史记录一起清除。

## 常见问题

**Q：ComfyUI 生成的图为什么被标成"A1111"？**

这批图的元数据是 A1111 兼容格式（常见于 Image Saver 等 Civitai 兼容保存节点、部分在线平台导出）。判断依据很直接：把这类图拖回 ComfyUI 时走的正是"读取 A1111 参数 → 自动转换工作流"的路径。无论哪种格式，提示词、步数、CFG、种子等参数都会完整解析展示，只是来源标签不同。

**Q：为什么显示"无元数据"？**

只有生图软件直接输出的原图才带参数。图片经过 Photoshop / Lightroom 处理、微信 / QQ 传输或网页转存后，生成参数通常会被剥离。此时详情页会显示具体检测线索（检测到的文本块、EXIF 软件字段等），帮助判断原因。

**Q：想只看某一类图？**

右上角来源筛选可切换 ComfyUI 原图 / A1111 / 无元数据 / 全部；配合模型筛选和搜索可以精确定位（比如搜某个模型名、LoRA 名称、种子或提示词片段）。

## 技术栈

Vue 3 + TypeScript + Vite + Naive UI，零运行时依赖的元数据解析（自实现 PNG chunk 解析与 EXIF TIFF 解析，zlib 解压用浏览器原生 `DecompressionStream`）。解析跑在 Web Worker 池里（按硬件线程数建 1-4 个，任务超时随文件大小自适应防止静默挂起），批量扫描时主线程只等结果不参与计算；Worker 中途失效自动重建池并重试，连续失效才整体回退主线程解析（并发同步收敛），行为一致。解析结果通过 IndexedDB 持久化（启动时以真实读写探测可用性，不可用即降级纯内存；大文本按内容寻址去重存储，启动恢复分批进行不阻塞首屏），Worker 池与回退编排以可注入传输实现并有独立单测。在线部署为 PWA（Service Worker：导航请求 network-first 保证每次部署后拿到新版本、离线回退缓存快照，静态资源 cache-first + Web Manifest），画廊虚拟滚动 + 预览 URL 惰性创建支撑万级大列表，排序复用 `Intl.Collator` 实例避免每次比较重建。主题色以 `src/theme.ts` 为单一来源，同时产出 naive-ui 主题与 `:root` CSS 变量（样式表静态声明仅作无 JS 首帧回退）。

## 元数据存储原理（参考）

- **PNG**：ComfyUI 通过 PIL 把 `prompt`（API 格式工作流 JSON）和 `workflow`（UI 格式工作流 JSON）写入 `tEXt` / `iTXt` 块，含非 Latin-1 字符（如中文）时 PIL 自动改用 zlib 压缩的 `iTXt`
- **JPEG / WebP**：EXIF `UserComment`（0x9286）；A1111 的 `parameters` 文本同样在此（ComfyUI 内置节点只输出带元数据的 PNG，JPEG/WebP 需要自定义保存节点）
- 解析时只读取文件头部切片（PNG / JPEG 的元数据位于图像数据之前），并按 256KB → 4MB → 整文件逐级放大，绝大多数文件一次小切片即可命中，扫描大量图片也很快；WebP 的 EXIF / XMP 块位于图像数据之后，解析器依 VP8X 标志对头部未命中的大文件逐级补扫
- 同一工作流批量出图的 prompt / workflow JSON 在主线程接收处做去重合并（interning），长列表常驻内存显著降低

> **提示**：`tests/fixtures/` 内有各类样例（ComfyUI tEXt / iTXt 中文 / 两阶段工作流 / A1111 / Photoshop 处理图 / 真实 ComfyUI 输出），`npm run test` 可验证解析器行为。
